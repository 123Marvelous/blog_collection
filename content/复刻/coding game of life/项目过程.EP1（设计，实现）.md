
### 1. 最小骨架实现 (Minimal Working Example) 
* **目标**：跑通 C 语言、Linux 远程开发以及 SDL2 图形库的最小闭环，成功在显示器上弹出一个窗口。
* **源码**：
```c
#include <stdio.h>
#include <SDL2/SDL.h> 
 int main() { 
	 printf("conway's game of life\n"); 
	 SDL_Init(SDL_INIT_VIDEO); SDL_Window *window = SDL_CreateWindow("Conway's Game of Life", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 900, 600, 0); 
 //查阅sdl2官方文档
	 SDL_Delay(5000); // 黑色窗口强制停留 5 秒 }
```

### 2. 编译与运行连招 由于引入了第三方 SDL2 图形库，普通编译会报错（找不到头文件/未定义引用）。必须配合环境自动配置工具。
* **硬核编译命令**：
```bash 
 gcc -o gol gol.c $(sdl2-config --cflags --libs)
``` 
> 💡 **避坑笔记**：这里的 `$(...)` 叫做命令替换，作用是全自动把系统里的库路径和链接参数 `-lSDL2` 贴到 `gcc` 后面，不需要背路径。




### 3. 🚨 踩坑记录 (远程图形输出困境) 
* **现象**：在 Windows VS Code 的 SSH 终端里运行 `./gol`，程序在后台跑了，但桌面上没有任何反应，按 `Ctrl + Shift + C` 也弹不出窗口。
* **原因（次元壁）**：SSH 连接属于纯文本通道，无法直接将虚拟机（Ubuntu）里运行的图形画面信号传输回 Windows 主机屏幕。
* **解决方案**：保持 SSH 编译，但必须切换到 **VMware 虚拟机的原生图形桌面** 去观察弹出的黑色窗口。
